# Kernel Nautico — Collaboration Deck Source

Status: source structure for a future company presentation.

The final presentation is owned by Editoriali + D-ND Design Kernel and should be
adapted to the actual receiver.

## Movement 1 — One product, many disconnected moments

A yacht is one product.

The knowledge that forms it may be distributed across:

~~~text
design
engineering
configuration
production
commissioning
delivery
service
lifecycle
~~~

Opening question:

**What changes if those moments remain part of one continuing operating field?**

## Movement 2 — Preserve the reasons, not only the files

Kernel Nautico can keep reachable the relation among:

~~~text
source
reason
decision
configuration
physical product
event
consequence
~~~

The objective is not to centralize every document.

It is to preserve what must remain meaningful as the product changes state.

## Movement 3 — FORM → BUILD → LIVE

~~~text
FORM
  intent / concept / design / engineering

BUILD
  configuration / components / assembly / commissioning

LIVE
  vessel / operation / service / lifecycle
~~~

The Kernel can participate differently in each state while preserving continuity
across them.

## Movement 4 — RETURN

The lifecycle is not terminal.

~~~text
real consequence
-> reusable difference
-> competence
-> later process / project / product
~~~

What happens after delivery can change what the organization can do next.

## Movement 5 — Learn the real company

Kernel Nautico is not a fixed shipyard template.

~~~text
domain kernel
+ actual company field
-> enterprise incarnation
~~~

It learns the real sources, tools, products, roles, constraints and useful
competences of the organization.

## Movement 6 — Begin with one complete relation

Do not propose transformation of the whole company at first contact.

Select one end-to-end relation that can prove continuity and learning.

Candidate structure:

~~~text
reason / requirement
-> engineering
-> configuration
-> physical product
-> commissioning
-> vessel identity
-> service event
-> consequence
-> later competence
~~~

Let the result determine the next depth.

## Closing

**Kernel Nautico is not an AI layer placed on top of a yacht company.**

It is a domain kernel that can become part of how the company understands,
develops and continues its products over time.
