# Kernel Nautico

Kernel di dominio MAIOS/D-ND per il campo nautico: sviluppo prodotto, cantiere,
azienda, imbarcazione e lifecycle.

Il repository nasce il 2026-10-02 dalla formazione iniziale condotta nel campo
Pershing / Ferretti. Ferretti è il primo campo di pressione, non il confine
semantico del kernel.

Il Kernel Nautico deve poter entrare in casi nautici non identici, comprendere
il campo reale, raggiungere le risorse pertinenti, formare competenze dalla
pratica e mantenere continuità fra progetto, prodotto e lifecycle.

## Stato

Il kernel è in formazione owner-native. La prima soglia è un **local operating
nucleus** capace di attraversare un movimento nautico completo, osservare le
conseguenze, apprendere e rientrare senza ricostruire il kernel creatore.

## Public development

Questo repository è pubblico per scelta.

La visibilità pubblica non determina da sola la futura forma commerciale,
di adozione o di licensing del Kernel Nautico. In questa fase non viene
aggiunta una licenza open-source permissiva per inerzia; la relazione di
adozione, collaborazione e sviluppo futuro resta un fronte separato da formare
con il Business owner.
