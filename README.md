# Kernel Nautico

**Un kernel operativo evolutivo per l’intero ciclo di vita di un prodotto nautico.**

Dal progetto alla costruzione. Dalla barca in esercizio al service. Dalle
conseguenze all’esperienza riusabile.

~~~text
FORM
-> BUILD
-> LIVE
-> RETURN
~~~

Kernel Nautico nasce per mantenere connesse le relazioni che normalmente si
disperdono fra persone, sistemi, documenti, decisioni, configurazioni e fasi del
prodotto.

L’obiettivo non è aggiungere un altro assistente AI al lavoro.

L’obiettivo è permettere all’esperienza di diventare **competenza** e cambiare
ciò che il sistema e l’organizzazione saranno capaci di fare dopo.

## Che cosa cambia

~~~text
fonti / decisioni / eventi / conseguenze
-> differenze riconoscibili
-> competenze
-> capacità più profonde nel lavoro successivo
~~~

Kernel Nautico può entrare in un’azienda reale, comprendere il suo ambiente e
formare capacità situate senza ridurre il dominio nautico a un template fisso.

## Un kernel di dominio, non un kernel Ferretti

Il primo campo di formazione è **Pershing / Ferretti**.

Questo non rende il kernel specifico per una singola azienda.

~~~text
Kernel Nautico
-> capacità di dominio nautico

+ ambiente reale di un’azienda
-> incarnazione enterprise

+ uno specifico progetto / yacht
-> relazione di prodotto / vessel instance dove utile
~~~

## Public base, situated value

Questa repository è pubblica.

Il sorgente e la struttura pubblica rendono il kernel ispezionabile e permettono
di valutarne l’architettura.

Il valore più profondo emerge però quando il kernel viene incarnato in un campo
reale:

~~~text
prodotti
+ processi
+ persone
+ strumenti
+ fonti
+ vincoli
+ conseguenze
+ competenze locali
-> capacità operativa situata
~~~

Una copia della repository non equivale a una incarnazione aziendale matura.

## Compounding capability

Il vantaggio non viene da un lock-in artificiale.

Viene dall’accumulo di capacità reale:

~~~text
più lavoro utile
-> maggiore comprensione situata
-> competenze più forti
-> integrazione più profonda
-> continuità migliore
-> maggiore valore nel lavoro successivo
~~~

## Stato corrente

Kernel Nautico è in formazione owner-native.

La prima soglia è **I1 — local operating nucleus**:

~~~text
recover field
-> recognize / reach pertinent resources
-> produce useful correctable result
-> observe consequence
-> return local reusable learning
-> reenter
~~~

senza ricostruire il kernel creatore.
