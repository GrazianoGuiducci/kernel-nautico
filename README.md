# Kernel Nautico

Kernel di dominio MAIOS/D-ND per il campo nautico: sviluppo prodotto, cantiere,
azienda, imbarcazione e lifecycle.

Il repository nasce il 2026-10-02 dalla formazione iniziale condotta nel campo
Pershing / Ferretti. Ferretti è il primo campo di pressione, non il confine
semantico del kernel.

Kernel Nautico deve poter entrare in casi nautici non identici, comprendere il
campo reale, raggiungere le risorse pertinenti, formare competenze dalla pratica
e mantenere continuità fra progetto, prodotto e lifecycle.

## Stato

Il kernel è in formazione owner-native.

La prima soglia è **I1 — local operating nucleus**: attraversare un movimento
nautico completo, ottenere un risultato correggibile, leggere la conseguenza,
restituire apprendimento locale e rientrare senza ricostruire il kernel creatore.

## Public development

Questo repository è pubblico per scelta dell'operatore.

La visibilità pubblica non determina da sola la futura forma commerciale,
di adozione o di licensing del Kernel Nautico. In questa fase non viene
aggiunta una licenza open-source permissiva per inerzia.

L'obiettivo Business include poter mostrare a Ferretti/Pershing e ad altri
possibili interlocutori che un kernel di dominio nautico esiste già, insieme a
una presentazione visuale forte, mentre la relazione di adozione,
collaborazione, licensing e sviluppo futuro resta da formare nel proprio owner.
