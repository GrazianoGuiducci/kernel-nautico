## Goal

Create one master visual system able to support:

- public GitHub encounter;
- 60–90 second hero film;
- Ferretti/Pershing-style collaboration presentation;
- technical one-page;
- site / interactive derivative;
- later Social Kernel distribution.

## One visual idea

**One yacht remains recognizable while the product and the operating intelligence
around it evolve.**

~~~text
FORM
-> BUILD
-> LIVE
-> RETURN
~~~

The camera/object relation should make continuity perceptible.

## What the viewer should understand

Without requiring D-ND vocabulary:

1. the same product crosses many organizational states;
2. reasons and knowledge can remain connected across those states;
3. the Kernel changes role as the product becomes real;
4. lifecycle consequence can become later competence;
5. a company incarnation learns the actual organization;
6. one vessel can later have its own legitimate situated field.

## Hero film skeleton

### 0–10s — FORM

A line becomes a yacht concept.

### 10–25s — ENGINEERING

Geometry opens into systems, reasons and configuration.

### 25–45s — BUILD

Exploded parts resolve into physical assembly.

### 45–60s — LIVE

The commissioned yacht enters operation.

### 60–75s — CONSEQUENCE

A service/lifecycle event exposes a meaningful difference.

### 75–90s — RETURN

The difference returns as competence and influences the next product movement.
