## What the current image establishes well

The reference is a premium dark-maritime presentation centered on one large
modern yacht at dusk/night.

Dominant field:
- deep navy/black background;
- warm ivory/gold highlights;
- cyan/blue technical traces used sparingly;
- luxury/engineering tone rather than consumer-app tone.

Composition:
- large "KERNEL NAUTICO" identity at upper left;
- hero yacht owns the upper field;
- technical/semantic support around it;
- lifecycle is made explicit as FORM / BUILD / LIVE / RETURN;
- a final continuation field suggests the cycle does not end at delivery;
- lower band translates the system into value dimensions.

Useful qualities to preserve:
- immediate nautical subject recognition;
- strong premium/industrial credibility;
- one dominant product object;
- lifecycle idea visible at a glance;
- technical intelligence without a cartoon robot/brain;
- warm accent traces that can become the continuity signature;
- clear bridge from product story to business/value story.

## What should NOT be copied literally into the Three.js demonstrator

The image is closer to a dense infographic/brochure than to the desired
interactive first encounter.

Do not reproduce:
- the full five-column information wall;
- every bullet/value label on first viewport;
- the exact yacht geometry;
- claims embedded in the image as if already verified;
- generic globe/network imagery for RETURN;
- apparent onboard "AI assistant", navigation/safety/control functions as current deployed capability;
- the exact page layout as an operational UI.

## Three.js translation

Contract the reference into:

~~~text
hero yacht
+ one continuity trace
+ four acts
+ minimal editable orientation copy
+ cinematic state transition
+ premium maritime environment
~~~

The browser demonstrator should feel like the reference image has become
**spatial and temporal** rather than like the image was rebuilt as a web page.

Suggested perceptual conversion:

~~~text
static hero yacht
-> persistent 3D yacht

FORM/BUILD/LIVE/RETURN panels
-> state machine / cinematic acts

gold/blue technical lines
-> continuity trace / semantic anchors

dense explanatory copy
-> progressive minimal labels

bottom value strip
-> later contextual explanation, not first-screen clutter
~~~

## External-receiver correction

The reference image assumes more context than a cold external receiver has.

The first live browser state must make it clear, with minimal text and the
visual sequence, that:
- Kernel Nautico is an AI/domain operating kernel;
- the yacht/product lifecycle is the object;
- continuity across phases is the central capability;
- experience can return as later capability.

Do not require the viewer to decode internal terminology before understanding
the object.
