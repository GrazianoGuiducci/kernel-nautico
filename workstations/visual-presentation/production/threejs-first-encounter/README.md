
## Primary experience

One persistent yacht is the visual owner.

The viewer moves through:

~~~text
FORM
-> BUILD
-> LIVE
-> RETURN
~~~

The yacht remains recognizable while its representation, context and semantic depth change.

The Kernel/AI is made visible by **meaningful continuity**, not a glowing brain,
generic neural net, chatbot bubble or decorative particle field.

## First execution boundary

Build a convincing first-encounter demonstrator.

It may include:
- autoplay/cinematic progression;
- FORM / BUILD / LIVE / RETURN controls;
- a small editable orientation layer;
- restrained orbit/inspection if it does not damage the narrative;
- one or a few semantic anchors;
- a continuity trace that survives state changes.

It must not include:
- operational dashboards;
- shipyard workflow software;
- bridge UI;
- permissions;
- CAD/PLM integration;
- autonomous navigation/control;
- invented Ferretti/Pershing collaboration;
- a full enterprise product implementation.
