## 6. New competence threshold

Do not create a new 3D competence merely because Three.js code was written.

A new competence becomes a candidate only if execution exposes a continuing
reusable function that:

- is not coherently owned by an existing Design or engineering method;
- changes later non-identical work;
- has a source-grounded method, not just a tool preference;
- can preserve provenance and effect boundaries;
- survives an actual exercise enough to justify a candidate owner.

Otherwise deepen an existing owner or return no_change.

A tool choice such as Three.js, Blender, GLB or WebGL is not itself a
competence.
