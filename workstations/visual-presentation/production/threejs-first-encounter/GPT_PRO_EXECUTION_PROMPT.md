## How the four states should read

### FORM

Show the yacht emerging from intent/geometry.

Possible techniques:
- wireframe overlay;
- ghosted material;
- sparse spline/line traces;
- two or three source/reason anchors.

Meaning:
the intelligence participates while the product is still reasons, constraints and form.

### BUILD

Same yacht, same camera ownership.

Increase engineering/material depth.

If the GLB is meaningfully segmented, use selected submesh separation/ghosting.

If it is not segmented, do **not** fabricate false systems.
Use:
- clipping/section;
- wireframe + solid coexistence;
- material state changes;
- semantic anchors;
- controlled exploded effect only on genuinely separate objects.

Meaning:
complexity grows but product identity and why-relations remain reachable.

### LIVE

The same yacht enters a restrained maritime environment.

Use water, horizon/light and calmer information density.

The transition must preserve recognition.

Meaning:
delivery/operation changes the field; it does not erase product continuity.

### RETURN

Introduce one illustrative lifecycle/service consequence.

Show:
event -> relevant product/context relation -> qualified returned difference -> later engineering/product/capability direction.

Do not use a decorative loop with no destination.

Meaning:
experience can change what later work is able to do.
