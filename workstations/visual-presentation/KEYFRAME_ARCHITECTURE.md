## Function

These nine keyframes are not nine slides.

They are **stable semantic states** from which the 3D master animation,
collaboration deck, investor cut, one-page and later interactive derivative can
be produced.

Each keyframe must carry:

~~~text
recognizable product state
+ current Kernel relation
+ one dominant perceptual event
+ one type of value
+ reality boundary
+ a clear transformation into the next state
~~~

The full animation lives in the transformations between them.

---

## KF-01 — INTENT / FIRST LINE

**Master phase:** FORM  
**Approximate film region:** 0–6 s

### Product state

The yacht does not yet exist as an object.

A single hull line / spatial trace begins to appear in a quiet field.

### Kernel state

External capability entering a field of intent, sources, requirements and
possibility.

### Perceptual event

The receiver sees that a product begins with relations and reasons before it
becomes geometry.

### Value made visible

**Understanding + continuity value.**

The visual establishes that preserving why something takes form can matter as
much as preserving the final file.

### Visual composition

- large negative field;
- one precise line becoming recognizable as nautical;
- sparse source/reason anchors;
- no generic AI icon;
- camera almost static.

### Reality boundary

Illustrative product-development relation.

### Reuse

Hero opening · deck cover transition · investor opening · site hero loop.

### Transition

The first line gains dimensions, references and alternative traces without
losing its origin.

---

## KF-02 — CONCEPT / FIELD BECOMES GEOMETRY

**Master phase:** FORM  
**Approximate film region:** 6–14 s

### Product state

Trace -> wireframe -> controlled concept volume.

The yacht becomes recognizable.

### Kernel state

Project participant: context, reasons, sources and current decisions are
situated around the emerging object.

### Perceptual event

The receiver sees the same intention acquire form while its reasons remain
reachable.

### Value made visible

**Operating value.**

The Kernel is not answering beside the project; it participates in the field
from which the project is taking form.

### Visual composition

- three-quarter concept view;
- selected plan/profile ghosts;
- translucent-to-solid transition;
- a few meaningful labels with editable text layer;
- one continuity trace survives from KF-01.

### Reality boundary

Concept-yacht study; no real Ferretti/Pershing design.

### Reuse

Public hero · collaboration deck "FORM" · product identity still.

### Transition

Camera settles; selected zones separate along intelligible engineering axes.

---

## KF-03 — ENGINEERING / RELATION OPENS

**Master phase:** FORM -> ENGINEERING  
**Approximate film region:** 14–25 s

### Product state

Recognizable yacht in controlled exploded / sectional state.

### Kernel state

The Kernel can help keep source, reason, design decision, configuration and
owner relations reachable while engineering depth increases.

### Perceptual event

Complexity opens without the product losing identity.

### R-01

Candidate continuity relation begins:

~~~text
source / reason
-> engineering definition
~~~

### Value made visible

**Continuity + integration value.**

Different engineering layers can remain distinct while participating in one
current field.

### Visual composition

- persistent hull silhouette;
- macro assemblies separated, not particle explosion;
- R-01 highlighted as one relation, not a fake real subsystem;
- source/reason marker visibly connected to the selected engineering state;
- technical callouts are sparse and editable.

### Reality boundary

R-01 remains illustrative and generic.

### Reuse

Collaboration deck · technical one-page · investor middle frame.

### Transition

Lines and schematic surfaces gain thickness, finish and material response.

---

## KF-04 — MATERIALIZATION / INFORMATION BECOMES MATTER

**Master phase:** BUILD  
**Approximate film region:** 25–34 s

### Product state

Engineering representation -> physical components / material states.

### Kernel state

Situated process capability: configuration and reasons remain connected while
the product crosses from representation into matter.

### Perceptual event

The receiver sees that the physical product is not a separate story from the
information that formed it.

### Value made visible

**Configuration + production continuity value.**

### Visual composition

- selected surfaces shift from schematic to material;
- ivory / metal / glass or later selected product palette;
- construction field suggested abstractly, not a false Ferretti factory;
- continuity traces adapt their graphic form rather than disappearing.

### Reality boundary

Conceptual shipyard/product process.

### Reuse

Hero · engineering/production deck movement · website transition.

### Transition

Macro components begin a coordinated assembly toward one complete yacht.

---

## KF-05 — ASSEMBLY / COMMISSIONING

**Master phase:** BUILD  
**Approximate film region:** 34–45 s

### Product state

Configured components -> assembled and commissioned vessel.

### Kernel state

Project/process capability approaches a product-specific boundary.

### Perceptual event

The receiver sees one product emerge from many states without losing its causal
history.

### R-01

~~~text
engineering definition
-> configuration
-> physical component/system
-> commissioning
-> vessel-specific identity
~~~

### Value made visible

**Process + handover + integration value.**

### Visual composition

- macro assemblies settle;
- final hull identity becomes dominant;
- engineering labels contract;
- commissioning/status marks replace construction marks;
- R-01 now visibly belongs to this vessel instance.

### Reality boundary

Vessel-specific Kernel remains horizon/illustrative unless later implementation
evidence exists.

### Reuse

Partner/collaboration keyframe · technical deck · hero midpoint.

### Transition

The technical floor becomes reflective, then gradually resolves into sea.

---

## KF-06 — LIVE / SAME OBJECT, NEW FIELD

**Master phase:** LIVE  
**Approximate film region:** 45–56 s

### Product state

Commissioned yacht -> vessel operating at sea.

### Kernel state

The company/project field can give way to a legitimate vessel-specific field
where such an incarnation exists.

### Perceptual event

The receiver recognizes the same yacht without a hard reset.

Delivery is a boundary, not the end of the causal story.

### Value made visible

**Lifecycle value.**

### Visual composition

- same camera ownership through environment transition;
- horizon and water emerge from prior technical plane;
- technical detail quiets rather than vanishes;
- continuity trace stays attached to the vessel.

### Reality boundary

Future vessel-kernel possibility remains distinct from current public domain
kernel.

### Reuse

Hero peak · investor lifecycle frame · collaboration deck LIVE movement.

### Transition

Camera enters/sections the already-recognized vessel.

---

## KF-07 — VESSEL KERNEL / SITUATED PRODUCT CAPABILITY

**Master phase:** LIVE  
**Approximate film region:** 56–66 s

### Product state

One specific yacht represented as a situated operating object.

### Kernel state

Possible vessel-specific relation:

~~~text
actual configuration
+ technical sources
+ component/system identity
+ lifecycle/service state
+ roles / permissions
+ specialist competence
-> situated vessel capability
~~~

### Perceptual event

The receiver sees that the onboard assistant, if present, is an interface to a
deeper product field rather than the product concept itself.

### Value made visible

**Product-instance + service + local/private knowledge value.**

### Visual composition

- controlled section or system focus;
- no omniscient glowing core;
- relation lines terminate in identifiable product/source/history objects;
- optional interface surface remains secondary.

### Reality boundary

Do not imply autonomous navigation, safety-critical control, unrestricted
telemetry or a deployed Ferretti vessel kernel.

### Reuse

Technical one-page · investor/product future · collaboration discussion.

### Transition

R-01 becomes the dominant focus because a lifecycle/service event makes it
pertinent.

---

## KF-08 — CONSEQUENCE / EXPERIENCE BECOMES DIFFERENCE

**Master phase:** LIVE -> RETURN  
**Approximate film region:** 66–78 s

### Product state

A service, maintenance, refit or operational event affects the selected R-01
relation.

### Kernel state

The system reconstructs the meaningful context around the event.

### Perceptual event

Not "more data arrives".

Instead:

~~~text
what is this?
how is this vessel configured?
why did this relation exist?
what happened?
which source / owner / competence matters now?
what consequence is reusable?
~~~

### Value made visible

**Competence + stewardship value.**

A useful consequence can become something the later system knows how to use.

### Visual composition

- tight focus with visible route back to whole vessel;
- event -> source/history/configuration relation;
- no generic dashboard rain;
- one returned difference becomes perceptually distinct.

### Reality boundary

The actual event remains illustrative until a qualified technical case is
selected.

### Reuse

Investor value frame · partner service/refit frame · hero consequence beat.

### Transition

The selected difference leaves the vessel only through an explicit governed
return path.

---

## KF-09 — RETURN / NEXT CAPABILITY

**Master phase:** RETURN  
**Approximate film region:** 78–90 s

### Product state

The completed yacht remains present as history while a new product movement
begins.

### Kernel state

~~~text
consequence
-> reusable difference
-> competence
-> changed later capability
~~~

### Perceptual event

A new first line appears, but it does not repeat KF-01 unchanged.

The field has learned something.

### Value made visible

**Compounding strategic value.**

The project can produce more than a yacht; it can produce capability.

### Visual composition

- lifecycle relation returns toward organization/product field;
- previous yacht remains a quiet stable reference;
- one changed relation participates in the next trace;
- new line begins;
- closure may carry editable copy, not baked raster text.

### Reality boundary

Do not visually claim automatic improvement or cross-vessel data sharing.

### Reuse

Hero close · investor close · collaboration close · social loop.

# Value map across the nine states

~~~text
KF-01  understanding / source-reason continuity
KF-02  operating participation
KF-03  engineering continuity / integration
KF-04  configuration-to-matter continuity
KF-05  process / commissioning / handover
KF-06  lifecycle continuation
KF-07  vessel/product-instance capability
KF-08  competence / stewardship
KF-09  compounding strategic capability
~~~

The investor/client presentation should not show all value labels simultaneously.
Each cut selects the value relations material to that receiver.

# First render proof

Do not render all nine as independent attractive images first.

Test **KF-01 -> KF-02 -> KF-03** as one coherent transformation triptych:

~~~text
first line
-> recognizable concept
-> engineering opening
~~~

Proof question:

> Does the same object become progressively richer while the source/reason
> relation remains legible, without needing a generic AI symbol?

If this fails, correct the persistent-object / continuity grammar before
building the rest of the film.
